## 🎮 About the Game

WheelMates is a two-player cooperative driving, platforming, and puzzle adventure developed and published by Firevolt. It released on September 1, 2026. Players control tiny RC cars through a professor's oversized home laboratory while solving environmental puzzles and investigating his disappearance.

---

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **WheelMates**. This trainer provides optional gameplay assistance for WheelMates, including movement support, puzzle convenience, exploration utilities, and customization-related adjustments. It is designed for the cooperative RC-car adventure and does not add combat mechanics.

**Target Audience:** Players who want extra convenience while exploring WheelMates, solving cooperative puzzles, practicing RC-car movement, finding secrets, or replaying the story with less frustration.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Use movement assistance during precision driving, narrow platforming sections, vertical routes, and traversal challenges involving ramps, magnetic wheels, or rope swings. Enable only the options needed for the current section so normal cooperative coordination remains intact.

### Tools & Inventory

WheelMates does not use a conventional item inventory. Progress is based on exploration, environmental interactions, journal discoveries, memory cards, scanned objects, gadgets, and puzzle completion. Trainer options should therefore focus on exploration and traversal rather than item duplication.

### World & Environment

Explore the professor's enormous home laboratory with a second player. Search shelves, desks, rooms, pools, workshops, and hidden paths for clues and secrets. The journal helps organize information gathered from scanned objects, memory cards, and the professor's scattered experiments.

### Combat & Weapons

There is no combat system in WheelMates. The main challenges come from driving, platforming, cooperative mechanisms, environmental hazards, puzzles, and discovering what happened to the missing professor.
